# LocalGloss 使用指南

## 开始输入

选择 LocalGloss 后输入全拼，例如 `kaifa`。中文候选右侧显示本地英文译词。没有释义时显示「暂无译词」，仍可用 Space 输入中文，不联网查询。

| 按键 | 组合输入时的行为 |
| --- | --- |
| Space / 数字 | 输入高亮中文 / 对应中文候选 |
| Tab / Shift＋Tab | 输入高亮候选的第一 / 第二条译词 |
| Option＋数字 / Shift＋Option＋数字 | 输入对应候选的第一 / 第二条译词 |
| ↑ / ↓ | 移动高亮候选 |
| Page Up / Page Down、− / = | 翻页；符号翻页可关闭 |
| F1（部分键盘需 Fn＋F1） | 展开或收起完整释义 |
| Page Up / Page Down（释义展开时） | 翻阅长释义 |
| Esc | 先收起释义，再次按下取消组合 |
| Enter | 原样输入拼音 |
| Ctrl＋Shift＋Space | 切换中文译词 / 英文直通 |

没有组合时，Tab、翻页符号等保持应用原有用途。候选窗口只显示、不能用鼠标选词；长译词可展开查看，实际提交不会按显示宽度截断。

## 设置和主动词条

在系统输入源菜单选择「LocalGloss 设置与词条…」。也可直接打开应用包内 `Contents/Resources/LocalGloss Settings.app`。

设置候选字号（14–22）、每页数量（3–9）、Tab 译词、符号翻页和中文标点。中文标点默认关闭。点击「保存设置」，切回输入窗口；若没有更新，切换一次输入法。

v0.3.0 预览版改用词条表格：搜索输入码、上屏文字或译词，选中后编辑或删除，点击「新增」逐条填写。表单显示字段校验与可滚动的完整 Space / Tab 预览；关闭 Tab 译词时，预览明确提示快捷键已关闭。译词为空时是否有译词以本地候选为准。v0.2.x 仍使用逐行文本格式。

alpha.3 开发版在编辑后保留仍符合搜索条件的词条选择；若修改后不再匹配，会提示清除搜索查看。无匹配结果会显示明确提示；原样确认词条不会新增撤销步骤。

修改先进入内存草稿，最多撤销最近 100 次词条修改；搜索不会改变保存顺序。点击「保存设置」才写入，关闭存在草稿的窗口会提示保存、放弃或取消。「放弃并重新加载」会先确认，然后读取磁盘配置。若其他窗口已保存，当前保存会拒绝覆盖，草稿继续保留。

同一个输入码只能配置一条，输入码限 1–32 个小写英文字母；文字最多 64 个 Unicode 字符，译词最多 240 个。三段都为单行，文字不能包含竖线；译词可留空。相同输入码的词条置顶。输入历史不会自动变成词条。

重复码、非法内容或过大的文件会被拒绝。加载旧文件失败时窗口禁止保存，避免覆盖原内容。手动编辑 JSON 时请保留全部字段和版本号；推荐使用设置窗口。

## 英文与符号

Ctrl＋Shift＋Space 进入英文直通后，字母和符号由目标应用处理；当前未提交拼音会原样提交。再次按下回到中文。Caps Lock 的英文直通行为保留。

中文模式输入 `:`、`/`、`@`、`_`、反斜线时，当前拼音原样提交，后续字符在同一 token 中放行，直到空格、回车或会话边界。网址、邮箱、代码建议先切英文直通；这不是系统英文输入源的完整替代。

中文标点开启时，`, . ? ! ;` 转为 `，。？！；`；有候选时先提交当前候选。LocalGloss 使用自己的离线拼音引擎，不能直接调用系统拼音的候选和学习词库。

## 安装与升级

当前稳定版为 v0.3.0。可以按 [安装说明](../../INSTALL.zh-CN.md) 获取应用；从源码构建时，先构建并检查 `dist/<时间戳>/LocalGloss.app`；构建脚本不会自动安装或结束任何进程。

首次安装：在 Finder 中将应用复制到 `~/Library/Input Methods/`，再到系统设置的键盘输入源添加 LocalGloss / 本地译词。如果系统要求重新登录，由使用者自行保存工作并安排，不由脚本触发。

更新已有版本：完成当前组合并切到其他输入源，备份精确的旧应用路径，再自行安排停止旧输入法进程和替换。不要在旧进程仍运行时覆盖后声称已升级。必要时恢复备份，重新选择旧版本输入源。

产物仅作 ad-hoc 开发签名，未做 Developer ID 签名与公证；不建议绕过未知来源的系统安全提示。完整验收见 [开发与验收](../development.md)。

## 候选排序

0.2.0 起，候选按拼音匹配程度和随包静态词频排序，常用词通常优先。完整拼音仍优先于补全；短简拼可能对应多个常用词，例如 `jx` 的首屏包含「进行、举行、继续」。继续输入完整拼音可缩小范围。

排序完全在本机完成，不记录输入，也不会根据输入习惯自动学习。少用词仍保留，可翻页查找；固定术语可在设置中主动添加。公开词频来自较旧语料，尚不具备系统输入法同等的整句与上下文预测能力。

## 0.2.1 测试版候选显示

候选行只显示 Tab 将输入的第一条释义；超出宽度时显示省略号，实际输入仍是完整第一条释义。F1 查看全部释义，Shift＋Tab 仍输入第二条释义。未改变原始译词或快捷键含义。

候选窗常规最大宽度从 620 点收窄到 560 点，随当前屏幕可用宽度调整；同一次组合通常保持宽度，移动到更窄的屏幕时允许缩窄。超长中文候选与英文仍分栏显示。极小显示区域下的详情高度、不同显示器与应用的实机效果仍待测试。

## 应用图标与安装渠道

输入法主程序与「LocalGloss 设置」使用统一的文／A 对话气泡图标；菜单栏保留简洁的 LG 标记。日常使用安装到当前用户输入法目录的 `LocalGloss.app`。`LocalGlossTest.app` 和 `LocalGlossPreview.app` 是开发验收工具，不属于下载包。

可按 [安装说明](../../INSTALL.zh-CN.md) 使用 Homebrew 或手动下载；两者下载相同发布包。测试版须明确选择 alpha 渠道，升级前保存工作、切换系统输入源并退出旧输入法。

## 中英候选与常用组合（下一测试版）

中文模式输入小写字母时，首屏提供「原样英文」候选，用数字键或选中后按 Space 提交；Enter 仍可直接提交当前输入。`ok`、`hello`、`yes` 等明确英文写法排第一，普通拼音中文首选保持不变，主动词条仍优先。原样候选没有译词，Tab 不会擅自消耗输入；大写字母、英文直通与网址邮箱路径保持原有行为。

`dous`、`doushi` 可选择「都是」。补充表还覆盖「也是、没有、还有、好的」等常用组合；已经选择前半段时，剩余拼音继续生成候选。这是固定短语与已有离线组合能力，不保证任意长句都有准确整句候选。

## alpha.5 中文候选

中文候选使用随应用提供的 Rime 简体词库，译词来自本地英文词典。`dous` / `doushi` 可选择「都是」；`ok` 等常用英文可直接选原样英文。普通拼音首屏末尾保留原样字母选项。同音词可能有多个合理结果，可用方向键或数字选择；候选排序不从个人输入自动学习。

这些候选改进从 alpha.5 起提供，v0.3.0 稳定版已包含这些行为。
