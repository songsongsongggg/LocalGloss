## 进入条件

## 本轮实现

- 独立 `localgloss-terms` / version 1 / terms JSON，仅交换主动词条。
- UTF-8、未知字段与版本、重复码、单行与 Unicode、500 条和 256 KiB 校验；整批错误不改变草稿。
- 新增、相同、冲突计数预览；冲突默认保留原项，允许逐项替换或取消整批；整批合并可撤销，其他偏好保留。
- 导出当前草稿，明确包含未保存的词条更改；不自动保存正式配置。
- 导出只创建新文件，不覆盖已有目标。这是相对早期“确认覆盖”方案的收窄：本轮不提供覆盖功能，避免目标变化时覆盖其他内容。
- 逐段目录描述符与 `O_NOFOLLOW` 拒绝父级或目标符号链接。读取 `O_NONBLOCK` 后验证普通文件与大小，避免 FIFO 阻塞；不扫描目录。
- 导出同目录 0600 临时文件，完成写入后 `linkat` 原子创建新目标；失败清理临时文件。不是跨文件系统事务或断电恢复承诺。
