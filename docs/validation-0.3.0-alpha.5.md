# LocalGloss alpha.5 本地修复验证

当前未发布、未安装。范围为英文原样候选、缺失常用组合与相应显示提示；不增加网络、自动学习、输入日志或个人输入采集。

## 根因与修复

- 现有门面未装配英文候选，新增首屏原样字母候选；固定明确英文写法优先，其他拼音保留中文首选，主动词条仍优先。
- CC-CEDICT 词库缺少「都是」等组合，单独增加项目编写、可审查的补充表；补 18 个缺失词形，保留已有词典数据。没有 jieba 权重的补充项使用明确标注的固定优先级。
- 原样候选按光标作用域提交；选前半段保留后半段拼音。没有译词的英文候选不会被 Tab 消耗。
