# LocalGloss alpha.5 发布前验证

发布前自动验证期间，本机使用 alpha.4 build 11，没有退出或覆盖正在使用的应用。本次范围为中英混输、Rime 中文候选与离线数据生成。

## 实现

- 中文主要候选改为固定 Rime pinyin-simp / Android Pinyin IME 快照，采用 Apache-2.0，保留 AUTHORS 和许可证。
- Rime 保留原权重，CC-CEDICT / 项目补充只添加缺失条目，权重为 1；不再使用 jieba 作为默认排名来源。
- 65,121 个 Rime 拼音条目加 82,127 个补充条目，共 147,248 个条目；跳过不支持的「〇」并过滤都是/都有/都要的 du 误读。
- 120,559 个有译词词形；64,424 个 Rime 词形中 39,240 个有译词，约 60.9%。缺译词不影响中文提交；不会联网补齐释义。
- 首屏保留原样英文，固定明确英文写法优先，主动词条优先不变；原样候选按光标作用域消耗。

## 自动验证

- 371 项 Rust、16 项 Python 测试通过；fmt / clippy 通过。
- Python 覆盖重复权重、零值、非法数据、读音过滤及源校验失败不留下部分输出。
- Swift 模型、保存与 Rust 读取/提交集成通过，只使用固定虚构配置。
- 181 组原有样例：174 组首选、181 组前三、181 组首屏；旧值为 170 / 179 / 181，未修改样例或冻结基线。
- 4 组预期词顺序下降：shiji 1→2、cipin 2→3、lianjie 1→2、zhishi 1→2，均仍在前三。质量门禁允许前三内同音顺序变化，但禁止原前三掉出前三、首屏掉出首屏、总体首选命中下降；所有下降单列 rank_changes，不称为逐项零退化。
- 30 组排序回放通过；shiji 同音首选接受世纪或实际，其余首选要求保留。
- ok / hello / yes 原样提交，dous / doushi 首选都是，没有/还有/也是/好的/我想提交通过。
- doushikaifa / woxiangkaifa 连续提交通过；单独选择都是后剩余 kaifa 可继续提交开发。
- Rime 独有的「我的」没有英文释义时，译词快捷键不消耗拼音，Space 仍提交中文。
- 混输和译词回放在 macOS sandbox-exec 禁止联网、禁止文件写入的环境中再次通过。该结果限于离线核心回放，不是系统输入法验收。
- 隐私结构检查：66 个运行时依赖、24 个门面 / 输入法源码文件通过；不增加网络、剪贴板监听、输入日志或自动学习。
- arm64 正式应用身份本地构建通过，152 个应用文件与构建清单一致，签名校验、内置词库哈希、logo 和许可文件完整。

## 验证边界

早期原型构建 source_dirty=true，不作为公开发行包；最终发布使用 source_dirty=false 的干净源码构建。源数据和许可已纳入源码导出白名单，导出不会上传。旧生成词库与当前 alpha.4 应用已在项目内备份。

发布前自动验证不包含安装后的系统输入法验收。真实 IMK 键盘、密码框、跨应用和完整动态隐私验收仍待安装后完成，不以编译、核心沙箱回放或结构检查替代。
