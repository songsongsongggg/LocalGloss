# v0.2.1-beta.1 本地验证

本版为本地测试版，2026-09-30 经用户确认已安装，尚未公开发布；v0.2.0 已备份可回退。保持原词库、静态词频、快捷键、设置格式和隐私依赖边界。

## 已完成

- 候选行使用独立的第一释义字段，与 Tab 的提交源一致；完整释义和第二释义提交保留。测试覆盖长译词、中文、释义内的字面分隔符，确认显示处理不截断上屏内容。
- 候选窗最大宽度 560 点，受当前屏幕可用宽度约束；中文栏最多占 40%。从宽区域切换到 320 点区域时验证可缩窄，同次组合正常情况下保留宽度，清空后尺寸重置。
- 366 项 Rust workspace 测试通过；格式、clippy、8 项 Python 数据测试、Swift 设置测试和隐私结构检查通过。运行时依赖仍为 66 个，未新增网络、剪贴板、输入日志或自动学习接口。
- 正常、长词、320 点窄区域和大字号详情四组原生离屏 PDF 已渲染检查，未发现分栏重叠。它们是布局检查，不是真实 IMK 会话或多显示器验证。

## 排序与性能

在实现改动前冻结 181 个公开、人工编写的输入样例，包含全拼、简拼、前缀、多音字和日常技术词；每五组留一组，共 36 组保留样例。没有使用个人输入，也没有根据本轮结果调词频。

| 样例 | 总数 | 首选命中 | 前三命中 | 首屏命中 |
| --- | --- | --- | --- | --- |
| 主集 | 145 | 137 | 143 | 145 |
| 保留集 | 36 | 33 | 36 | 36 |
| 合计 | 181 | 170 | 179 | 181 |

与 v0.2.0 基线相比没有候选排名退化。这里的「命中」指预先写定的可接受词集合；短简拼不保证猜中每次意图。「离线」仍为第 4，一组 `sz` 的接受词位于第 8，保留为已知排序边界。

相同 release 构建条件下，第一轮预热，随后三轮采样，共 3,222 次逐键操作：

| 指标 | 改动前 | 改动后 |
| --- | --- | --- |
| 首次引擎加载 | 90.62 ms | 107.68 ms |
| 预热逐键 p50 | 0.248 ms | 0.258 ms |
| 预热逐键 p95 | 0.426 ms | 0.458 ms |

p95 增幅约 7.4%，低于计划的 20% 门槛。首次加载指新引擎实例，系统文件缓存未清空，不能称为冷盘基准。数据来自本机单轮前后对照，未包括 AppKit 绘制、IMK 回调或真实键盘端到端耗时，不是跨设备性能承诺。

## 可复现入口

```sh
bash scripts/dev.sh cargo run --offline --locked --release -p localgloss-engine --example quality_check -- assets/cedict/generated crates/localgloss-engine/examples/fixtures/baseline.txt
bash scripts/dev.sh cargo run --offline --locked -p localgloss-macos --example candidate_preview -- target/candidate-preview
```

质量报告默认输出到标准输出。传入冻结基线时，样例定义不一致或任何已知词排名下降均报错。CI 保留原 30 组首选断言，并增加 181 组质量回归。计时只报告，不在共享 CI 上使用单次耗时硬阈值。

## 待验收

新版已安装且启动状态验证通过；真实键盘、浏览器/编辑器焦点切换、密码框、持续网络与文件写入观察、多显示器均未重新执行。极小显示区域下的详情高度仍待专项验证，当前修复限定窗口宽度。自动按键工具此前不能可靠触发 IMK，不用它替代用户物理键盘结果。

v0.2.0 已备份，新版安装文件哈希、签名和实际词表回归已通过；下一步只用虚构文本执行真实键盘会话验收。该版本不能直接据自动测试升级为稳定版。
