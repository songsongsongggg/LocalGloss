# v0.2.0 验证记录

日期：2026-09-28。环境：Apple Silicon、macOS 26.7（25G229）。本次稳定版沿用已安装并试用的 0.2.0-beta.2-dev 实现和词表，仅更新版本标识、构建号与发布文档。

## 实际使用验收

维护者在本机试用后反馈「常见的输入是合理的」「目前测试是很好的」，并明确批准稳定版发布。这证明本机常见输入体验获得用户认可，不等同于所有快捷键、应用或安全边界都已完成逐项验收。

前期安装测试确认：注册、启用与选择输入源成功；新进程使用当前用户安装目录；已安装文件符合构建清单。空密码框触发 Secure Input 并切换离开 LocalGloss。局部观察未见 TCP/UDP socket，更新前后剪贴板变化计数一致；没有读取密码或剪贴板内容。

## 可重复检查

- Rust workspace：364 项测试；格式与 clippy 检查。
- Swift 设置：保存、权限、原子替换、无效内容保护及符号链接拒绝。
- Python 数据转换：8 项测试，覆盖归档校验、词频边界与少见读音降权。
- 完整词表：30 组排序回归与 10 组翻译流程；可在禁止网络和文件写入的 macOS 沙箱中执行。
- 数据固定快照、许可证、转换结果与应用文件哈希；嵌套签名、arm64 架构和压缩包解压验证。
- GitHub CI：以 v0.2.0 标签对应提交的 Actions 检查为准。

排序检查使用公开固定样例，测试不读取个人设置或历史。`jix` 首选「继续」，`jx` 首选「进行」且「继续」位于前三；不能由此推断所有拼音都能猜中意图。

## 尚未覆盖

尚未完成所有 macOS 版本、目标应用、多显示器、持续网络与文件写入观察，以及完整密码框和跨应用焦点回归。自动按键注入在此前对照实验中不可靠，因此不作为 IMK 端到端通过证据。

发布渠道为稳定版；该决定基于维护者实际使用验收和明确授权，替代此前要求完整动态验收后才发布稳定版的计划。剩余范围公开保留，后续继续验证。应用仍为 ad-hoc 签名，未公证，也未完成独立安全审计。
