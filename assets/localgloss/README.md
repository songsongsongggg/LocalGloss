# LocalGloss 常用表达补充表

`common-phrases.tsv` 由 LocalGloss 贡献者编写，按 CC BY-SA 4.0 分发。四列为中文、无声调拼音、缺少 jieba 词频时使用的固定优先级、英文释义。

这是针对词典未收录的常用组合编写的小型补充表，不是个人输入记录或真实语料频次，也不是通用整句语言模型。优先保留 CC-CEDICT 已有读音与释义。alpha.5 的中文候选使用 Rime 权重；这张表的缺失词条只以权重 1 补入，第三列为历史转换兼容字段，不影响当前 Rime 排序。来源文件哈希、实际新增条数记录在生成清单中。

英文释义为通用提示，需要结合语境使用；如「都是」的 `all are` 不能自动适配整个句子的语法或时态。英文原样候选是当前输入字母，不是云识别或自动补全。
