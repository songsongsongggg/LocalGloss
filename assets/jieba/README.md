只读取词形与频次，按简体词形匹配 CC-CEDICT。未匹配词保留为权重 1；重复词取最大频次，零频次按 1 处理。87,754 个拼音条目匹配到词频，其余词仍可查询。没有引入 jieba 运行库或联网功能。

jieba 的词频不是现代输入法的个人使用概率，也不区分读音。转换脚本对「见/xian、听/yin、区/ou、行/heng、什/shi、的/di、说/shui」使用固定的 1/100 权重修正，避免少见读音继承常见读音的全部权重；该修正是排序规则，不是语料统计。

词频与修正规则在构建时合并到 CC-CEDICT 派生 TSV。派生表继续按 CC BY-SA 4.0 提供，保留本来源的 MIT 声明。应用只查询合并结果；不采集用户输入、不自动学习、不写入输入历史，也不读取系统输入法的个人词库。

局限：旧语料可能偏向新闻、书面语和历史地名；短简拼存在歧义，候选不一定符合每次意图。低频词降权而不删除，可继续输入完整拼音或使用主动词条。
